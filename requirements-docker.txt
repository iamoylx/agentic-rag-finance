# 容器镜像专用依赖（与 requirements.txt 的差别：容器里没有「系统继承」，必须自含）
#
# torch 为什么不写在这里：
#   装 CPU 版必须用 `--index-url https://download.pytorch.org/whl/cpu` **替换**默认索引，
#   否则 pip 会从 PyPI 拿到 CUDA 构建（镜像凭空多 2-3 GB，而容器里 `EMBED_DEVICE=cpu`
#   根本用不到 GPU 版）。但 `--index-url` 写进 requirements 文件会污染**同文件所有包**的
#   索引（PyPI 上的 fastapi / chromadb 就找不到了）。
#   → torch 单独一条命令装，见 Dockerfile。
#
#   原先这里写的是 `--extra-index-url` + `torch>=2.4.0`：两个索引并存时 pip 按「最高版本」
#   挑，PyPI 的 torch 往往同时命中，是否真拿到 CPU 版**是不确定的**——构建结果不可复现。

-r requirements.txt
